# せーので一致

お題に全員が同じ答えを書けるまで終われない、みんなのスマホで遊ぶパーティーゲームです。

**遊ぶ**: https://kazuhiro5.github.io/seeno-icchi/

## 遊び方

1. 1人が「部屋を作る」と、4けたの部屋番号が出ます。
2. ほかの人は同じページを開き、番号を入れて参加します。
3. 親が問題数（3〜20問）と書く時間を選んで「スタート」。全員の画面に、ランダムなお題「〇から始まる△△」と制限時間が出ます。
4. 時間内に、それぞれ答えを書きます（ほかの人には見えません）。
5. 時間切れか全員が決定すると締め切ります（時間切れの時は、親が＋15秒・＋30秒を足せます）。親が「せーので オープン！」を押すと答えのカードが裏向きで並び、親がタップした人から1枚ずつめくれます。
   お題が出る時は「デデン」と鳴ります（右上のボタンで消せます）。退出は画面下の「退出する」を2回押します。
6. 全員そろえば一致。一致してもしなくても、次の問題へ進みます。
7. 最後の問題が終わると、何問中何問一致したかが出ます（途中で終えることもできます）。

## しくみ

- サーバーは使っていません。親のブラウザが部屋の役をし、[PeerJS](https://peerjs.com/)（WebRTC）で参加者とつながります。
- そのため、親が画面を閉じると部屋が終わります。
- ひらがな・カタカナ・全角半角・空白の違いは同じ答えとみなします。
